# CalhaPro — Calhas Oliveira

Sistema da Calhas Oliveira para orçamentos, clientes, recibos e serviços.

## Instalar no computador

Acesse os [lançamentos para Windows](https://github.com/MatheusHolDev/CalhaPro-Releases/releases/latest) e baixe o instalador mais recente.

## Usar no Android

Abra o [CalhaPro Mobile](https://matheusholdev.github.io/CalhaPro-Releases/) no Chrome e escolha **Instalar app** ou **Adicionar à tela inicial**. O app mobile sincroniza dados com a conta Supabase somente depois do login.

As alterações do app mobile são publicadas automaticamente a partir do repositório privado de código.
