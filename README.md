# CalhaPro — lançamentos

Este repositório distribui os instaladores do CalhaPro para Windows e os arquivos usados pelo atualizador automático.

- [Baixar a versão mais recente](https://github.com/MatheusHolDev/CalhaPro-Releases/releases/latest)

Os dados cadastrados no aplicativo permanecem armazenados localmente no computador.
